# RAOUTE

> **AI-powered travel planning platform for exploring the United States.**

## Overview

Planning a trip across the United States can involve switching between maps, travel guides, restaurant websites, review platforms, and countless browser tabs.

**Raoute** is a travel-planning platform concept designed to bring destination discovery, route planning, and personalized itinerary planning into one experience.

This repository contains the **official showcase website for Raoute**. The website introduces the project's concept, visual identity, planned features, technology direction, and development vision.

The full Raoute travel-planning application is currently under development and is not included in this repository.

Raoute began as my first independent software project and an exploration of how **artificial intelligence and software engineering** can be applied to a real-world travel-planning problem.
